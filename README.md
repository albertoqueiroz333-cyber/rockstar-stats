Dependências e Versões Necessárias

Liste as dependências necessárias para rodar o projeto e as versões que você utilizou.

    Uvicorn - Versão: 0.54.0

    Python - Versão: 3.15
    Starlette - Versão: 1.8.0

Como rodar o projeto ✅
 
 instale o docker
